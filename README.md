# Spring Boot TODO API

REST API для управления списком задач. Проект выполнен в рамках учебного задания по настройке CI/CD.

## Технологии

- Java 21
- Spring Boot 4.1.2
- Maven
- JUnit 5
- MockMvc
- JaCoCo
- Docker
- GitHub Actions
- GitHub Container Registry (GHCR)

## Возможности API

Приложение позволяет создавать, просматривать, изменять и удалять задачи.

| Метод | Адрес | Описание |
|---|---|---|
| POST | `/tasks` | Создать задачу |
| GET | `/tasks` | Получить список задач |
| PUT | `/tasks/{id}` | Изменить задачу |
| DELETE | `/tasks/{id}` | Удалить задачу |
| GET | `/actuator/health` | Проверить состояние приложения |

Пример тела запроса для создания задачи:

```json
{
  "title": "Изучить Spring Boot",
  "description": "Разобраться с REST API",
  "completed": false
}
```

Поле `title` обязательно для заполнения.

## Запуск приложения

Для запуска необходимы Java 21 и Maven.

Сборка и запуск тестов:

```bash
mvn clean verify
```

Запуск приложения:

```bash
mvn spring-boot:run
```

После запуска приложение доступно по адресу:

`http://localhost:8080`

## Docker

Сборка Docker-образа:

```bash
docker build -t todo-app .
```

Запуск контейнера:

```bash
docker run -p 8080:8080 todo-app
```

Проверка состояния приложения:

`http://localhost:8080/actuator/health`

## CI/CD

Для автоматизации сборки используется GitHub Actions.

Настроенный pipeline выполняет:

1. Получение исходного кода из GitHub.
2. Настройку Java 21.
3. Сборку проекта и запуск тестов.
4. Проверку покрытия кода с помощью JaCoCo.
5. Сохранение JAR-файла как артефакта сборки.
6. Сборку Docker-образа.
7. Публикацию Docker-образа в GitHub Container Registry.

Docker-образ публикуется в:

`ghcr.io/liza-sig/spring-boot-todo-cicd:latest`
